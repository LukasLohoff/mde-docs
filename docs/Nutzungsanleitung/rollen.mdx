# Rollen

Folgende Rollen sind im Metadateneditor (MDE) implementiert:

- Datenhaltende Stelle - DHS
  - Kann neue Datensätze anlegen
  - Kann bestehende Datensätze bearbeiten
- Redakteur
  - Ergänzt Datensätze, die von einer DHS angelegt wurden
  - Kann selbst neue Datensätze erfassen
- Qualitätssicherung – QS
  - Übernimmt die fachliche und formale Prüfung der Datensätze
- Administrator
  - Kann alle Datensätze bearbeiten
  - Kann Statusänderungen vornehmen

Beim Anmelden am MDE wird die Rolle automatisch über die Software Keycloak ermittelt. Angemeldete Nutzende erhalten entsprechend ihrer Rolle die jeweiligen Berechtigungen und Funktionen.
