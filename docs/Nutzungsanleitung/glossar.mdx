# Glossar

- **Actuator** – Spring Boot Monitoring-Tool für Systemüberwachung
- **AD** – Active Directory
- **API** – Application Programming Interface
- **ATOM** – Atomfeed-Protokoll für Daten-Downloads
- **Attribut** – Datenfeldbezeichnung in Geodaten
- **Backend** – Serverseitige Geschäftslogik und Datenverarbeitung
- **BE** – Berlin
- **BITV** – Barrierefreie-Informationstechnik-Verordnung
- **CI/CD** – Continuous Integration/Continuous Delivery (automatisierte Build- und Releaseprozesse)
- **Client** – Webbasierte Benutzeroberfläche (Frontend)
- **Compose** – Werkzeug zur Orchestrierung von Container-Anwendungen
- **CRS** – Coordinate Reference System
- **CSW** – Catalogue Service Web
- **CSW-T** – Catalogue Service Web - Transactional
- **DB** – Datenbank
- **DE** – Deutschland
- **DHS** – Datenhaltende Stelle
- **DNS** – Domain Name System
- **Docker** – Container-Plattform
- **Elasticsearch** – Such- und Analysedienst
- **EN** – English
- **EPSG** – European Petroleum Survey Group Geodesy
- **ETF** – European Testing Framework (Validierungswerkzeug für INSPIRE)
- **FeatureType** – Feature-Typ (Objektklasse in Geodatendiensten)
- **Frontend** – siehe Client
- **GDI** – Geodateninfrastruktur
- **GDI-DE** – Geodateninfrastruktur Deutschland
- **GEMET** – General Multilingual Environmental Thesaurus
- **GHCR** – GitHub Container Registry
- **GIS** – Geographisches Informationssystem
- **GNOS** – GeoNetwork Open Source
- **GUI** – Graphical User Interface (Grafische Benutzeroberfläche)
- **Healthcheck** – Automatisierte Systemüberwachung
- **HTTP** – Hypertext Transfer Protocol
- **HTTPS** – Hypertext Transfer Protocol Secure
- **HVD** – High Value Dataset (Hochwertige Datensätze nach EU-Verordnung)
- **IAM** – Identity and Access Management (Identitäts- und Zugriffsverwaltung)
- **INSPIRE** – Infrastructure for Spatial Information in the European Community
- **ISO** – International Organization for Standardization
- **JSON** – JavaScript Object Notation
- **JSONB** – JSON Binary (binäres JSON-Format in PostgreSQL)
- **Keycloak** – Identity und Access Management Software
- **Keystore** – Speicher für Zertifikate und Schlüssel
- **Layer** – Kartenebene in Geodatendiensten
- **LDAP** – Lightweight Directory Access Protocol
- **LDAPS** – LDAP über SSL/TLS
- **Log4j2** – Java-Logging-Framework
- **Lucene** – Suchindex-Technologie
- **MDE** – Metadateneditor
- **METEOR** – Metadaten- und Themeneditor
- **NGINX** – Web-Server und Reverse Proxy
- **NTP** – Network Time Protocol (Zeitsynchronisation)
- **OGC** – Open Geospatial Consortium
- **Podman** – Container-Plattform
- **PostgreSQL** – Relationale Datenbank
- **QS** – Qualitätssicherung
- **Realm** – Keycloak-Bereich für Benutzerverwaltung
- **REST** – Representational State Transfer
- **Reverse Proxy** – Vermittlungsserver für eingehende Anfragen
- **SLD** – Styled Layer Descriptor
- **Spring Boot** – Java-Framework für Backend-Anwendungen
- **SSL** – Secure Sockets Layer
- **Style** – Darstellungsvorschrift für Kartenebenen
- **SvelteKit** – Framework für Frontend-Anwendungen
- **TLS** – Transport Layer Security
- **UML** – Unified Modeling Language
- **UMTHES** – Umweltthesaurus (Schlagwortkatalog für Umweltthemen)
- **URL** – Uniform Resource Locator
- **UUID** – Universally Unique Identifier
- **WFS** – Web Feature Service
- **WMS** – Web Map Service
- **WMTS** – Web Map Tile Service
- **XML** – Extensible Markup Language
- **XSD** – XML Schema Definition
