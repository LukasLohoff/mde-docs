# Betriebliche Rollen und Verantwortlichkeiten

Die Rollenbeschreibung erfolgt bewusst auf grober Ebene:

- Betriebsverantwortung Infrastruktur: Hostbetrieb, Containerlaufzeit, Netz,
  TLS, Backup-Infrastruktur
- Betriebsverantwortung Identity and Access Management (IAM):
  Keycloak-Realm, Rollenmodell, Föderation, Benutzerlebenszyklus
- Fachadministration MDE: Kodelisten, Variablenmapping, Freigabeprozesse im
  Anwendungskontext
- Anwenderrollen im System: `MdeAdministrator`, `MdeDataOwner`, `MdeEditor`,
  `MdeQualityAssurance`
