# Konfiguration per Codelisten

Der Metadateneditor nutzt Codelisten im YAML-Format zur fachlichen Konfiguration. Über Codelisten ist es möglich, anwendungsspezifische Einstellungen vorzunehmen, ohne Änderungen am Quellcode durchführen zu müssen.

Die Codelisten liegen im Repository `mde-deployment`: https://github.com/gdi-be/mde-deployment/tree/main/codelists
Die Konfigurationshinweise sind den dort hinterliegten entsprechenden README.md-Dateien zu entnehmen.
